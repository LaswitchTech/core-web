# Apache Configuration

## Purpose

The Apache Configuration generator produces an .htaccess file with mod_rewrite rules that route all non-static-file requests to the application entry point for deployments on Apache HTTPD servers.

## Responsibilities

_(none)_

## Public API

### `generate(string $subdir = ''): string`

Generate an .htaccess file with mod_rewrite rules that route all non-static-file requests to the application entry point.

**Behavior**:
- Takes a `$subdir` parameter (relative to DocumentRoot). Empty string (`''`) means root deployment, any path means subdirectory under `/DocumentRoot/subdir/`.
- Root deployment: outputs `RewriteEngine On` with conditions that skip real files/directories and route everything else to `index.php`.
- Subdirectory deployment (e.g. `$subdir = '/app'`): adds `RewriteBase /app/` so routing is relative to the subdirectory URL prefix. The RewriteBase value is derived as `/{$trimmed}/` where `$trimmed = trim($subdir, '/')`, defaulting to `/` when empty.
- Both modes include a mod_rewrite block and an autoindex-blocking block (`Options -Indexes`).
- Multiple consecutive blank lines between `RewriteEngine On` and the first comment are intentional (from template formatting).

### `writeToFile(string $path, string $subdir = ''): ?string`

Write the generated .htaccess content to disk atomically (temp file + rename).

Returns the written path on success, `null` on failure.

## Generated Output Examples

### Root deployment (generate(''))

```apache
# Apache .htaccess — Core-Web Router (root deployment)
# Auto-generated by Laswitchtech\\CoreWeb\\Router\\Config\\Http\\Apache::generate()
# Do not edit manually; regenerate with `core.deploy apache` or via admin panel.

<IfModule mod_rewrite.c>
    RewriteEngine On




    # Skip requests that map to real files or directories.
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d

    # Route everything else to index.php.
    RewriteRule . index.php [L]


</IfModule>

# Block access to hidden files/dirs (.git, .env, etc.).
<IfModule mod_autoindex.c>
    Options -Indexes
</IfModule>

```

### Subdirectory deployment (generate('/app'))

**RewriteBase**: `/app/` **(for `$subdir = 'app'`) and `{rewriteBase}` resolves to `/app/` in the template. The empty-lines block (three blank lines between `RewriteEngine On` and first comment) is intentional — currently unused spacing from the original template:

```apache
# Apache .htaccess — Core-Web Router (subdirectory deployment)
# For deployments at /app/ your URL prefix is "app".
# Auto-generated by Laswitchtech\\CoreWeb\\Router\\Config\\Http\\Apache::generate()
# Do not edit manually; regenerate with `core.deploy apache` or via admin panel.

<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /app/




    # Only route when the request does NOT map to a real file/directory.
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d

    # Send remaining requests to the app's index.php (relative to RewriteBase).
    RewriteRule . index.php [L]


</IfModule>

# Block access to hidden files/dirs (.git, .env, etc.).
<IfModule mod_autoindex.c>
    Options -Indexes
</IfModule>

```
